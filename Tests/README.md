# Текущие проверки JustEnoughTools

Набор относится только к действующему функционалу. Проверки удалённых профилей и прежней диагностики удаления отсутствуют.

| Файл | Что проверяется |
|---|---|
| `Program.cs` / CoreTests | .NET Framework, встроенные ресурсы, числовая версия файла |
| `Portability/PortabilityTests.cs` | x64, manifest, DPI, единственный EXE с системным runtime; самопроверка без соседних зависимостей и собственных файлов |
| `Security/SecurityEngineTests.cs` | Фиксированный каталог защиты, блокировка Tamper Protection, доступность команды и фактический статус защиты в реальном времени после попытки записи |
| `PowerShellTests.cs` | Передача фиксированного скрипта через stdin, строгий UTF-8, неполный ввод, синтаксические ошибки, коды завершения и большой вывод; только безвредные команды |
| `SecurityCoordinatorTests.cs` | UAC по необходимости, IPC, проверка входных данных и передача результатов |
| `TaskbarTests.cs` | Фиксированное исправление панели задач, откат при отказе, встроенное действие EXE |
| `TweakTests.cs` | Независимые поддействия, неизвестные состояния, граница прав, один запрос на пакет, IPC, сохранение автозагрузки, обход файлов и отмена |
| `Export/ExportTests.cs` | Сохранение EXE, ICO, безопасная перезапись и версия ресурсов |
| `Export/ShortcutTests.cs` | Собственные ярлыки, перенос файлов, сохранение чужих ссылок и обновление иконок |
| `UI/UiTests.cs` | Карточки, выбор иконок, размеры, DPI, независимые отчёты, инструкция Tamper Protection и повторная проверка без изменений |
| `Updates/UpdateTests.cs` | Пакет обновления, манифест, дельты, fallback, состояния загрузки |
| `Updates/HttpBodyTests.cs` | Отмена и таймаут загрузки после HTTP-заголовков; вызывается UpdateTests |
| `Updates/InstallerTests.cs` | Установка, перезапуск, блокировки и сохранение исправного EXE; вызывается UpdateTests |

Проверки выпуска и происхождения EXE находятся в `.github/tests`. Это часть действующей публикации: номер коммита, единственное число версии, отпечаток исходников, манифест и дельты.

Защита Windows и реальная панель задач в автоматическом наборе не меняются. Для системных действий используются подставные адаптеры, для установки обновлений — безвредные тестовые EXE в собственном временном каталоге.

```powershell
.\Tests\Test.ps1 -ExecutablePath .\JustEnoughTools.exe
.\.github\tests\ReleaseTests.ps1
```

Исторические результаты отдельных выпусков хранятся в [архиве документации](../docs/verification-history.md). Они не являются дополнительными тестами текущей сборки.
